Parcial 1

Actividades del Parcial 1

Cada tarjeta dirige a una actividad de este parcial: introducción, objetivo, código comentado, conceptos principales y el PDF descargable del entregable.

Act 1

ACTIVIDAD 01 - Análisis en grupo de un ciberataque real

Analizar en equipo el ataque NotPetya (2017) contra A.P. Møller–Maersk, evaluando su impacto bajo el modelo CIA, su costo económico y su relación con marcos normativos como ISO/IEC 27001 y NIST CSF.

  • NotPetya
  • ISO 27001
  • NIST CSF
→ Act 2

ACTIVIDAD 02 - Portafolio del curso

Diseño, desarrollo y despliegue del portafolio digital del curso: header, presentación, perfil, información técnica y formulario de contacto con autorespuesta, publicado en GitHub Pages con HTTPS.

  • Portafolio
  • GitHub Pages
  • EmailJS
→ Act 3

ACTIVIDAD 03 - No presiones Esc… todavía pynput

Implementar y documentar, en un entorno de laboratorio controlado, un programa basado en event hooks y callbacks que permita registrar eventos de teclado.

  • Python
  • pynput
→ Act 4

ACTIVIDAD 04 - Una página demasiado convincente

Implementar y analizar, en un entorno de laboratorio aislado, una simulación de phishing con el módulo Credential Harvester de Social-Engineer Toolkit (SET), para reconocer los indicadores técnicos y visuales de una página fraudulenta.

  • SET
  • Phishing
  • Kali Linux
→ Act 5

ACTIVIDAD 05 - Ingeniería Social (el arte del engaño)

Cuestionario basado en un video sobre un caso real de estafa con criptomonedas (caso Lam Malone), aplicando conceptos de ingeniería social y sus técnicas de manipulación.

  • Ingeniería Social
  • Fraude
  • Criptomonedas
→ Act 6

ACTIVIDAD 06 - Road to Hall of Fame

Diseñar e integrar en el Portafolio Digital un nuevo módulo web denominado ROAD TO HALL OF FAME, que estructure y presente de forma visual, organizada y profesional los laboratorios, incorporando evidencias técnicas, navegación funcional y un botón de descarga del documento completo.

  • Hall of Fame
  • Documentación técnica
  • Desarrollo Web
→ Act 7

ACTIVIDAD 07 - Lab: File Path Traversal Simple Case

Informe técnico sobre la explotación de la vulnerabilidad de salto de directorio (Path Traversal / Directory Traversal), recuperando el archivo sensible /etc/passwd mediante la manipulación del parámetro filename en la carga de imágenes.

  • Path Traversal
  • Linux
→ Act 8

ACTIVIDAD 08 - Lab: Traversal Sequences Blocked with Absolute Path Bypass

Informe técnico sobre el bypass de filtros defensivos que bloquean secuencias relativas (../) mediante el uso de rutas absolutas directas desde la raíz del sistema de archivos para acceder a /etc/passwd.

  • Absolute Path
  • Bypass
  • Control de Acceso
→ Act 9

ACTIVIDAD 09 - Lab: Traversal Sequences Stripped Non-Recursively

Informe técnico sobre la evasión de filtros de sanitización no recursivos mediante la inyección de secuencias de salto anidadas (....//) para reconstruir el payload destructivo tras la supresión de caracteres.

  • Non-Recursive
  • Nested Payloads
  • Sanitization Bypass
→ Act 10

ACTIVIDAD 10 - Lab: Traversal Sequences Stripped with Superfluous URL-Decode

Informe técnico sobre la explotación de salto de directorio evadiendo filtros de entrada mediante doble codificación URL (%252e) y decodificación redundante o superflua en la capa del servidor web.

  • Double Encoding
  • Superfluous Decode
  • WAF Bypass
→ Act 11

ACTIVIDAD 11 - Lab: Validation of Start of Path

Informe técnico sobre la evasión de validaciones de inicio de ruta (starts-with) al mantener el prefijo base autorizado (/var/www/images/) y concatenar secuencias relativas de retroceso para escapar del directorio confinado.

  • Prefix Validation
  • Start of Path
  • Path Traversal
→ Act 12

ACTIVIDAD 12 - Lab: Validation of File Extension with Null Byte Bypass

Informe técnico sobre la inyección de un terminador de byte nulo (%00) para truncar la lectura de rutas en llamadas nativas a la API del sistema de archivos, eludiendo la validación de extensión requerida (.jpg).

  • Null Byte (%00)
  • Extension Bypass
  • String Truncation
